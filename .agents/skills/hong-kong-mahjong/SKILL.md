# Hong Kong Mahjong Reference

Read only the references needed for the task. Read several when a question crosses topic boundaries. Treat the material as a description of one ruleset rather than a universal standard; flag house-rule choices and variants when they matter.

## Tile tokens

Interpret compact tile tokens as follows:

- `[1D]`–`[9D]`: dots
- `[1B]`–`[9B]`: bamboo
- `[1C]`–`[9C]`: characters
- `[E]`, `[S]`, `[W]`, `[N]`: winds
- `[RD]`, `[GD]`, `[WD]`: red, green, and white dragons
- `[F1]`–`[F4]`: flowers associated with east, south, west, and north
- `[S1]`–`[S4]`: seasons associated with east, south, west, and north
